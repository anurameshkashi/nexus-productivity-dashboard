# NEXUS — Productivity Dashboard

🚀 **Live Demo:** [View NEXUS Live](https://anurameshkashi.github.io/nexus-productivity-dashboard/)

A modern, responsive productivity and analytics dashboard built with HTML, CSS, and JavaScript.

## Overview
NEXUS is a modern productivity and analytics dashboard designed to help users manage tasks, track productivity, and visualize their progress through a clean, responsive interface.

## 🚀 Features

- 📊 Productivity analytics dashboard
- ✅ Task management with Kanban board
- 🔄 Drag-and-drop task organization
- 📅 Interactive calendar
- 📈 Productivity charts and statistics
- 🌙 Dark / Light mode
- 🔍 Task search and filtering
- 💾 LocalStorage data persistence
- 📱 Fully responsive design
- ⚡ Modern SaaS-style user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SVG Charts
